กลับไปยังแผนที่

นโยบายความเป็นส่วนตัว

Map Phayao / FarmTech ให้บริการแผนที่ การวิเคราะห์ความเหมาะสมของพื้นที่เกษตร และการจัดการข้อมูลแปลงของผู้ใช้ นโยบายนี้อธิบายข้อมูลที่ระบบใช้และบริการภายนอกที่เกี่ยวข้อง

ข้อมูลที่ใช้และวัตถุประสงค์

  • ระบบใช้ LINE ID token เพื่อยืนยันตัวตนกับเซิร์ฟเวอร์ และใช้ตัวระบุ LINE ที่ผ่านการตรวจสอบเพื่อเชื่อมกับบัญชีผู้ใช้ภายในและกำหนดสิทธิ์เข้าถึงแปลง ชื่อที่แสดงจาก LINE อาจใช้แสดงในข้อมูลผู้ใช้
  • เมื่อผู้ใช้เลือกตำแหน่งหรือวาดแปลง ระบบใช้พิกัดและขอบเขตแปลงเพื่อวิเคราะห์ข้อมูล GIS และสภาพอากาศ เมื่อบันทึกแปลง ระบบจัดเก็บขอบเขต ชื่อแปลง ชนิดพืช พันธุ์ วันที่ปลูก และข้อมูลที่เกี่ยวข้อง
  • รูปภาพที่ผู้ใช้เลือกแนบกับแปลงถูกปรับเป็น WebP ก่อนอัปโหลด เพื่อแสดงและจัดการรูปภาพของแปลงนั้น

การจัดเก็บและบริการภายนอก

  • Supabase PostgreSQL/PostGIS จัดเก็บบัญชีผู้ใช้ แปลง เจ้าของแปลง ขอบเขต และข้อมูลธุรกิจของแปลง แต่ไม่จัดเก็บไฟล์รูปภาพแปลงหรือข้อมูลกำกับรูปภาพแปลง
  • Google Drive จัดเก็บไฟล์รูปภาพแปลง Google Sheets เก็บสำเนาข้อมูลผู้ใช้และแปลงเพื่อการอ่าน รวมถึงรายการชื่อรูปภาพและลิงก์รูปภาพในช่อง Image และ LinkImage
  • เซิร์ฟเวอร์ส่งพิกัดที่ใช้วิเคราะห์ไปยัง Open-Meteo เพื่อขอพยากรณ์อากาศ และใช้ข้อมูล GIS/ภัยพิบัติจากผู้ให้บริการที่แสดงในผลวิเคราะห์
  • เว็บไซต์เผยแพร่ผ่าน Netlify และ API ทำงานบน Render การเข้าสู่ระบบใช้ LINE LIFF

การเข้าถึง ความปลอดภัย และการลบข้อมูล

การเข้าถึงข้อมูลแปลงและรูปภาพผ่าน API ต้องผ่านการตรวจสอบ LINE และสิทธิ์เจ้าของแปลงบนเซิร์ฟเวอร์ ไฟล์ใน Google Drive ไม่ถูกตั้งให้เป็นสาธารณะโดยอัตโนมัติ การสื่อสารกับบริการภายนอกใช้การเชื่อมต่อที่เข้ารหัส

ผู้ใช้สามารถลบแปลงของตนผ่านแอป การลบจะลบข้อมูลแปลงจากฐานข้อมูลและพยายามลบรายการใน Google Sheets และรูปภาพที่เกี่ยวข้องใน Google Drive การซิงก์หรือลบข้อมูลจากบริการภายนอกอาจไม่สำเร็จในบางครั้ง ระบบไม่ได้กำหนดระยะเวลาเก็บรักษาข้อมูลที่ตายตัวไว้ในแอป
